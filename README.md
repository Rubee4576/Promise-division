# Task 15 - JavaScript Promises

## Objective

Create a JavaScript function that performs division using Promises.

## Features

- Uses an arrow function.
- Takes two numbers as input.
- Returns a Promise.
- Resolves the Promise with the division result.
- Rejects the Promise when the second number is zero.
- Tested with 5 different cases.

## Test Cases

1. 10 / 2 = 5
2. 10 / 0 = Error
3. 20 / 4 = 5
4. 25 / 5 = 5
5. 7 / 2 = 3.5
